# Cowboy trader hat design preview

This standalone preview runs the real frontend from source commit `73509eac78d5442953a702d2f5c46eb2bcacf5d1`. It opens the leaderboard by default. Trader hats use the same Cowboy icon with address-derived colours and backgrounds. Open a trader profile or use Markets → Flow and coin wallet lists to see the same identity throughout the product. Names, ranks and all financial data remain unchanged.

It embeds the exact published site-data snapshot from commit `584035d6ff2e1f0937f91427581505fd337cdf69`, generated on 5 October 2026 at 21:17:33 UTC. No data fields are invented or altered. The clock is frozen at that snapshot, fonts and coin icons are embedded, browser routing uses hashes, analytics are omitted, and live execution and exchange connections are disabled.

The generated HTML belongs only on the isolated preview branch, not in the production frontend.
