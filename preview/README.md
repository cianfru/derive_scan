It embeds the exact published site-data snapshot from commit `584035d6ff2e1f0937f91427581505fd337cdf69`, generated on 5 October 2026 at 21:17:33 UTC. No data fields are invented or altered. The generated HTML belongs only on the isolated preview branch, not in the production frontend.
